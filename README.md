# The Backrooms

This is a high-quality Unity project that brings the eerie and unsettling world of the Backrooms to life. The game leverages Shader Labs for enhanced visual effects and atmosphere, creating an immersive and realistic experience.

## Play the Game
Experience the Backrooms here: [The Backrooms on Itch.io](https://mrkopchick.itch.io/the-backrooms)

## Features
- **High-quality graphics** powered by Shader Labs
- **Atmospheric horror** experience
- **Smooth performance** using optimized C# scripts

## Technologies Used
- Unity Engine
- Shader Labs
- C#
